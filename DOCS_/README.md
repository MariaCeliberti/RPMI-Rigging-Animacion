# RPMI-Rigging-Animacion
Descripción del proyecto

Proyecto de rigging y animación 2D realizado con Duik Angela en Adobe After Effects, utilizando personajes y elementos gráficos creados en Adobe Illustrator.

El proyecto incluye un personaje principal completamente preparado para animación mediante sistema de controladores IK y controles faciales, además de elementos adicionales ilustrados para apoyo visual y efectos de escena.

Contenido del proyecto
Personaje principal

El personaje principal ha sido diseñado en Illustrator y preparado para animación en After Effects mediante Duik Angela.

Sistema de controladores implementado

El rig incluye los siguientes controladores:

Controladores IK de pies
Controladores IK de brazos
Controlador de cadera
Controlador de caja torácica
Controlador de cuello
Controlador de cabeza
Controladores faciales
Elementos adicionales

También se incluyen elementos secundarios diseñados en Illustrator:

Mosca
Sangre

Estos elementos están preparados para ser utilizados como apoyo visual y efectos dentro de la animación.

Objetivo del proyecto

El objetivo principal del proyecto es desarrollar un sistema de rigging funcional para animación 2D, optimizando el control del personaje y facilitando la producción de animaciones expresivas y fluidas.
